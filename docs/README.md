# 项目文档

文档按用途分层，后续开发按任务选择性读取。

| 入口                                  | 用途                                    | 默认读取         |
| ------------------------------------- | --------------------------------------- | ---------------- |
| [ARCHITECTURE.md](ARCHITECTURE.md)    | 当前生效的分层、职责和不可违反的边界    | 仅跨层或架构任务 |
| [development/](development/README.md) | Route、Feature、Service、组件等实施指南 | 只读任务相关文件 |
| [decisions/](decisions/README.md)     | 已接受架构决策的背景、取舍和影响        | 理解或改变决策时 |
| [archive/](archive/README.md)         | 历史方案与执行快照                      | 不默认读取       |

代码、配置和测试是当前实现的事实来源。文档与实现不一致时，应明确报告差异；归档不能作为当前规范。
